# Upstream policy

MemoryCreep is an independent project derived from
[PentestAgent](https://github.com/GH05TCREW/pentestagent).

The last common baseline recorded when the project became independent is:

```text
b09a106557f5a83d3427a24c7058f930e39aac4d
```

MemoryCreep has its own architecture, security policy, roadmap, release process,
and maintainership. Upstream changes are not merged automatically. Maintainers
may fetch upstream for review and cherry-pick a narrowly scoped security fix
after it passes MemoryCreep's policy, test, and isolation checks.

The retained `pentestagent` Python package, class names, environment variables,
and compatibility entry points are implementation interfaces. They do not
indicate affiliation with or endorsement by the original maintainers.
